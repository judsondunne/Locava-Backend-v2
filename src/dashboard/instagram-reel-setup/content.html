Instagram reel download pipeline

Collect reel URLs from an Instagram profile in Chrome, paste into the Backendv2 admin downloader, resolve direct MP4 links (yt-dlp → Cobalt → scrape fallbacks), and download locally.

Chrome extension

instagram-reel-link-extension

Scrolls reels grids, builds Reels JSON with captions + comment snippets.

Backendv2

Admin downloader + APIs

Batch resolve, optional session cookies, browser MP4 download — all native to Backendv2.

Cobalt

Self-hosted resolver

Local instance at 127.0.0.1:9000 — fallback when yt-dlp fails.

⚡ Quick start (local dev)

  1. Load instagram-reel-link-extension/ in Chrome (Developer mode → Load unpacked).
  2. Start Backendv2: cd "Locava Backendv2" && npm run dev (port 8080).
  3. Run Cobalt on port 9000 and install yt-dlp on the same machine.
  4. Open /admin/instagram-downloader → paste Reels JSON → Fetch all reels → download MP4s.

1 Install the Chrome extension

Source: Locava-Master/instagram-reel-link-extension/ — manifest v3, name Locava Instagram reels.

  1. Open Chrome → chrome://extensions/
  2. Enable Developer mode (top-right toggle).
  3. Click Load unpacked and select the folder containing manifest.json: 
    Locava-Master/instagram-reel-link-extension/
  4. Pin Locava Instagram reels to your toolbar.
  5. Stay logged into Instagram in the same Chrome profile — the extension uses your tab session for caption fetches.
Content script: content-script.js runs on instagram.com and sends live profile stats (followers, following, posts) to the popup via background.js.

2 Collect reel URLs

  1. Open an Instagram profile or reels tab, e.g. https://www.instagram.com/someuser/reels/
  2. Click the extension icon. The popup shows live stats scraped from the page.
  3. Optionally set Max reels (blank = all visible after scrolling).
  4. Click Get reel links. The extension:
    • Injects collectReelLinksInPage() — finds every a[href*="/reel/"], scrolls until 3 stale rounds
    • Fetches each reel page (~480ms apart) for og:description, caption JSON, comment snippets
    • Builds Reels JSON in the textarea via buildReelsJsonDoc()
  5. Click Copy JSON — paste into /admin/instagram-downloader. Or Copy links only for URL-per-line mode.

Reels JSON shape

{
  "version": 1,
  "source": "locava-instagram-extension",
  "username": "handle",
  "pageUrl": "https://www.instagram.com/handle/reels/",
  "collectedAt": "2026-07-11T…",
  "reels": [
    {
      "url": "https://www.instagram.com/handle/reel/SHORTCODE/",
      "shortcode": "SHORTCODE",
      "titleOrCaption": "Caption text…",
      "commentsPreview": [{ "text": "Nice!" }]
    }
  ]
}

Session cookies (optional)

Paste a JSON array exported from your browser into the admin downloader (or extension popup). Sent as cookies in resolve requests — helps when server IP is rate-limited. 

[{"domain":".instagram.com","name":"sessionid","value":"…"}, {"domain":".instagram.com","name":"csrftoken","value":"…"}]

Never commit cookie JSON.

3 Set up Cobalt

Backendv2 reads Cobalt config from src/lib/instagram-reel/cobaltConfig.ts. Default: http://127.0.0.1:9000.

  1. Clone and run Cobalt — follow imputnet/cobalt docs: 
    git clone https://github.com/imputnet/cobalt.git
cd cobalt
docker compose up -d
# API listens on port 9000 by default
  2. Add Instagram cookies to Cobalt (strongly recommended): 
    # In Cobalt docker-compose / environment:
COOKIE_PATH=./cookies.json
  3. Optional outbound proxy: API_EXTERNAL_PROXY=http://user:pass@proxy:port
  4. Point Backendv2 at Cobalt (only if not on localhost:9000): 
    # Locava Backendv2/.env
COBALT_INSTANCE_URL=http://127.0.0.1:9000
COBALT_API_KEY=your-api-key   # optional
  5. Install yt-dlp on the Backendv2 machine (tried before Cobalt): 
    brew install yt-dlp
YTDLP_PATH=/usr/local/bin/yt-dlp
YTDLP_COOKIES_FILE=/path/to/instagram-cookies.txt

What Backendv2 sends to Cobalt

POST {COBALT_BASE}/
Content-Type: application/json

{
  "url": "https://www.instagram.com/reel/SHORTCODE/",
  "videoQuality": "max",
  "downloadMode": "auto"
}

Use canonical https://www.instagram.com/reel/{code}/ URLs — profile-prefixed URLs often return error.api.fetch.empty.

4 Verify Cobalt is working

Run these checks in order. Replace SHORTCODE with a real public reel. Backendv2 default port is 8080.

Step 1 · Cobalt direct
curl -s -X POST http://127.0.0.1:9000/ \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.instagram.com/reel/SHORTCODE/","videoQuality":"max","downloadMode":"auto"}'
✓ status: tunnel, redirect, success, or picker
Step 2 · Backendv2 probe
curl -s http://127.0.0.1:8080/admin/instagram-downloader/api/probe
✓ cobaltBase, cobaltSource, envFiles in response
Step 3 · Resolve a reel
curl -s -X POST http://127.0.0.1:8080/admin/instagram-downloader/api/resolve \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.instagram.com/reel/SHORTCODE/"}'
✓ ok: true + videoUrl + method field
Step 4 · Admin UI probe button
Open http://127.0.0.1:8080/admin/instagram-downloader
Click "Check Cobalt"
✓ Cobalt base URL shown in probe panel
All green? Cobalt responds, Backendv2 probe shows your instance URL, a test shortcode resolves with ok: true.
  • Cobalt container running on port 9000
  • COOKIE_PATH set on Cobalt with valid Instagram cookies
  • Backendv2 running with Cobalt URL configured in .env
  • yt-dlp installed on Backendv2 host
  • Test reel resolves via curl

5 Admin Instagram downloader

/admin/instagram-downloader — paste JSON/URLs, optional cookies, fetch + download MP4. Native resolve APIs on Backendv2. No Firebase, no Wasabi, no user attach.

Workflow

  1. Paste Reels JSON from the extension (or one reel URL per line).
  2. If resolves fail, expand Session cookies (optional) and paste browser cookie JSON.
  3. Click Fetch all reels — sequential resolve, 3400ms spacing (900ms with cookies), 5 auto-retries.
  4. Review results table (status, method, caption).
  5. Download per-row or use Download all resolved.

How cookies are processed (server-side)

From instagramCookieHelpers.js: filters to instagram.com domains, builds Cookie header, writes temp Netscape cookies.txt for yt-dlp (deleted after each request).

6 Download Instagram clips

A · Admin downloader (recommended)

  1. Paste Reels JSON or URLs into /admin/instagram-downloader
  2. Optional: paste session cookies
  3. Click Fetch all reels
  4. Download per-row or batch — files save as instagram-{shortcode}.mp4

B · Direct API

After resolve returns videoUrl, download via POST /admin/instagram-downloader/api/file with the CDN URL and optional sourceUrl / shortcode for muxed audio.

Rate limits: Space resolves 3.4s apart (0.9s with session cookies). Split batches over 45 URLs if you see 429s.
